## 三、采集行为约定

1. 每个关键词每日 1 轮；单关键词每日新增上限建议 30 条，防止刷屏挤占人工确认带宽。
2. 去重键维持 `source_job_id` 不变。
3. 新关键词岗位照常进 scoring / greeting 生成管线，但**必须保持"机器收集、人工确认"边界：不自动发送**，只有用户标记 `approved` 的岗位才可进入发送环节。
4. `status` 字段语义（ready / approved / sent / filtered / rejected / error）本次不变。
5. filtered 过滤规则本次**不动**（用户稍后自行 review 误杀问题，已知误杀案例：蔚森智能 AIAgent 应用实习生、星云深图 AI Agent 实习生 300-400/天）。

1. 配置生效后 24 小时内，`jobs` 表出现 `source_keyword` 为新增词的记录，且城市仅广州/佛山；

3. `collection_runs` 无 failed 记录；
4. 向用户汇报一次新旧关键词的抓取数量对比。
